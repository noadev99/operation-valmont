# Vrais enregistrements (facultatif)

Chaque son du jeu est fabriqué par le navigateur. Pour le remplacer par un vrai enregistrement,
dépose un fichier audio ici avec le nom exact ci-dessous (.mp3, .wav, .ogg ou .m4a), puis lance `python3 build.py`.
Le jeu l'utilisera à la place, automatiquement.

| Fichier | Son |
|---|---|
| alarm.mp3 | Sonnerie d'alarme de la banque |
| siren.mp3 | Sirène de police |
| beep.mp3 / refus.mp3 | Badge accepté / refusé |
| steps.mp3 | Pas dans l'escalier |
| blackout.mp3 | Coupure de courant |
| vault.mp3 | Porte de la chambre forte |
| gong.mp3 | Cloche de 6h00 |
| talkie.mp3 | Talkie-walkie des gardes |
| dice.mp3 | Dé qui roule |
| thunder.mp3 | Tonnerre (intro) |
| type.mp3 | Touche de machine à écrire (intro) |
| boom.mp3 / whoosh.mp3 / riser.mp3 / stinger.mp3 | Impacts et transitions de l'intro |
| amb-gala.mp3 | Ambiance en boucle : le gala (foule, quatuor) |
| amb-nuit.mp3 | Ambiance en boucle : la nuit |
| amb-tension.mp3 | Ambiance en boucle : tension |
| amb-pluie.mp3 | Ambiance en boucle : pluie |
| amb-film.mp3 | Musique de l'intro |

Sons gratuits et libres de droits : Pixabay (pixabay.com/sound-effects), Freesound (freesound.org, vérifie la licence).
