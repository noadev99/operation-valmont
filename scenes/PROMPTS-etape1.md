# Étape 1 (l'entrée dans la banque) : 6 situations × 3 états × 3 versions = 54 images
Situations : crochetage, camera, hack, garde, badge, escalier
États : action (en train), ok (réussite), ko (échec)
Versions : duo (les deux), a (seul : cheveux bruns tirés en arrière), b (seul : longs cheveux, casquette à l'envers)
Noms : <situation>-<état>.png pour le duo, <situation>-<état>-a.png et <situation>-<état>-b.png en solo
